# gate-api-version allowlist — FuzeKeys
#
# Every HTTP route the Fuze family exposes lives under /api/v{N}/
# (CLAUDE.baseline.md §4.3, FuzeSDLC governance/api-versioning.md). This file
# records the routes that predate that standard so the gate fails only what is
# NEW. It is DEBT TO BURN DOWN, NOT APPROVAL. Nothing may be added to it to make
# a new route pass.
#
# WHY THIS FILE EXISTS AT ALL, rather than the routes simply being moved:
# moving them is a breaking API change for every existing caller — the mobile
# app, the Playwright automation, and the FuzeFront shell all address these
# paths today. The standard's own guidance is to record and migrate, not to
# break callers in the commit that adopts the gate. The migration is tracked
# separately; this file is what keeps master green until it lands.
#
# HOW TO REMOVE AN ENTRY: move the route under /api/v1, update its callers in the
# same PR, then delete the line here. The gate will tell you if you missed a
# caller. Deleting a line without moving the route turns master red, which is the
# intended behaviour.
#
# ---------------------------------------------------------------------------
# SECTION 1 — NOT FUZEKEYS' SURFACE. Do not "burn these down".
# ---------------------------------------------------------------------------
# These are third-party paths, fixed by someone else's convention, reached
# through someone else's base URL. They are listed only because the gate cannot
# distinguish `f"{their_base_url}/api/x"` from `f"{our_base_url}/api/x"` — both
# are an /api/ literal following an interpolation. Changing either of these would
# BREAK the integration, not improve it.

# Ollama's completion endpoint. backend/app/llm_scraper_service/llm_integration/
# llm_client.py:227 — `requests.post(f"{self.base_url}/api/generate", ...)`,
# where base_url is the Ollama server. Ollama defines this path; we do not.
/api/generate

# A documentation URL constructed for a THIRD-PARTY SITE record, not a route this
# service serves. backend/init_test_db.py:307 — `f"{base_url}/api/docs"`, the
# fallback when a site has no known docs URL. base_url is the scraped site's.
/api/docs
